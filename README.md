# 3D Basketball Game

## About the Project
This project is a 3D Basketball Game developed using C++ and OpenGL as part of the Computer Graphics subject.

The game displays a 3D basketball court, basketball, and basket. The ball can be controlled using keyboard keys.

## Features
- 3D basketball court and hoop
- Moving basketball
- Score display
- Keyboard controls
- Translation
- Rotation
- Scaling
- Reflection

 ## Keyboard Controls

 Key        Function 

 Space      Shoot the ball 
 A / D      Move the ball left and right (Translation) 
 Q / E      Rotate the ball 
 1 / 2      Decrease / Increase ball size (Scaling) 
 F          Apply reflection 
 R          Reset the game 

## Computer Graphics Transformations
1. Translation: Moves the basketball from one position to another.
2. Rotation:Rotates the basketball.
3. Scaling: Increases or decreases the basketball size.
4. Reflection: Reflects the basketball.

## Technologies Used

- OpenGL
