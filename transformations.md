# Computer Graphics Transformations

## 1. Translation
Translation moves an object from one position
to another in the 3D space.

## 2. Rotation
Rotation turns an object around a particular axis.

## 3. Scaling
Scaling increases or decreases the size of an object.

## 4. Reflection
Reflection creates a mirror image of an object
across a selected axis or plane.

## Application in Basketball Game
These transformations demonstrate how objects
can be moved, rotated, resized and reflected
using computer graphics.
